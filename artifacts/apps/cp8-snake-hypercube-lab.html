CP8 Snake // Hypercube Lab v1.1

This single-file app contains the original grid game and a working Snake-in-a-Box laboratory with an explicit CP8 mathematical layer.

STRUCTURAL RULE

Consecutive states must have Hamming distance 1. A candidate state is rejected when it is already visited or is distance 1 from any earlier nonconsecutive state. This is the induced-path constraint.

CP8 MATH CORE

428 Core is the binary structural verifier. 528 Fusion is normalized Shannon entropy of the flipped-bit distribution. 963 Integration is path coverage |P|/2ⁿ. Their weighted composite is transparent and auxiliary; it never replaces the proof rules.

φ-GUIDED SEARCH

The worker uses onward-degree ordering and a deterministic golden-angle tie break at 137.507764°. Identical dimension, strategy, and seed parameters generate the same candidate order. Time-limited search remains heuristic and is not a maximum-length certificate.

ANU-28

The 28 glyphs are semantic routing metadata only. Their index advances with path depth and is exported in the receipt. Frequency labels are namespaces, not physical-effect claims.

PROOF EXPORT

Export creates canonical JSON containing the path, verifier, CP8 metrics, search parameters, ANU-28 state, claim boundary, and SHA-256 content seal.
