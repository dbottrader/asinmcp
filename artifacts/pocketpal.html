Load it in five minutes

  1. Install PocketPal from the Google Play Store (free, "PocketPal AI"). Open it once so it creates its folders.
  2. Get the model onto the phone — download it from the link above, or transfer it by USB / Drive. Remember the folder (e.g. Download).
  3. Import it: PocketPal → Models → add / import a local model → pick the GGUF file. After import you can delete the transfer copy.
  4. Load it from the model picker (a few seconds).
  5. Create the pal: new Pal named ASIN-HHC; open our SYSTEM-PROMPT.md, copy everything below the line, paste it as the pal's system prompt, save.
  6. Chat. Try "What is ASIN-HHC?" and "How does Proof of Pay work?"
